# 数据库初始化脚本说明

## 文件位置
`packages/prisma/seed.ts`

## 功能介绍

该初始化脚本会创建以下基础数据：

### 1. 系统角色
- **admin**: 系统管理员，拥有所有权限
- **user**: 普通用户，可以发布和管理自己的文章

### 2. 管理员用户
- **邮箱**: admin@blog.com
- **密码**: admin123456
- **昵称**: 系统管理员
- **权限**: 管理员角色

### 3. 默认分类
- 技术分享 (tech)
- 生活随笔 (life)
- 项目实战 (project)
- 学习笔记 (notes)

### 4. 常用标签
JavaScript, TypeScript, Node.js, NestJS, Vue.js, React, PostgreSQL, Prisma, Docker, AWS

### 5. 示例文章
- 标题: "欢迎来到我的博客"
- 内容: 介绍博客系统技术栈和使用方法
- 分类: 技术分享
- 标签: JavaScript, NestJS

## 使用方法

### 运行初始化脚本
```bash
# 从项目根目录执行
pnpm db:seed
```

### 完整数据库重置和初始化流程
```bash
# 1. 重置数据库（删除所有数据并重新运行迁移）
pnpm db:reset

# 2. 运行初始化脚本
pnpm db:seed
```

### 开发环境快速启动
```bash
# 1. 推送数据库schema（如果没有迁移）
pnpm db:push

# 2. 运行初始化脚本
pnpm db:seed
```

## 注意事项

1. **脚本幂等性**: 使用 `upsert` 操作，可以重复运行而不会产生重复数据
2. **密码安全**: 管理员密码使用 bcrypt 加密存储
3. **环境变量**: 确保设置了正确的 `DATABASE_URL` 环境变量
4. **数据依赖**: 确保数据库迁移已成功运行后再执行种子脚本

## 自定义配置

如需修改初始化数据，可以直接编辑 `seed.ts` 文件：

- 修改管理员账号信息
- 添加更多分类和标签
- 创建更多示例文章
- 调整用户的默认角色分配

## 故障排除

如果遇到错误，请检查：
1. 数据库连接是否正常
2. 迁移是否已成功运行
3. 环境变量是否正确设置
4. 依赖包是否正确安装
